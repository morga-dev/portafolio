# Mi portafolio personal

Portafolio digital minimalista, enfocado en mostrar algunos de mis proyectos y habilidades.

🔗 **Sitio en vivo:** [diego-morga](https://diego-morga.vercel.app/)

## 🚀 Stack Tecnológico

- **Framework:** Next.js (App Router)
- **Biblioteca UI:** React
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Gestor de paquetes:** pnpm

## ✨ Características

- **Diseño Editorial:** Estética oscura, limpia y minimalista.
- **Alto Rendimiento:** Construido con Server Components para una carga ultrarrápida.
- **Sección de Proyectos:** Conexión y visualización de repositorios destacados.
